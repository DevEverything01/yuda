# ADR 0010: 语音修改上一段

- 状态：accepted
- 日期：2026-10-14

## 背景

豆包输入法支持用语音修改刚说的话（「把 A 改成 B」）。语打运行在 Wayland 上，通过剪贴板 + 模拟粘贴上屏（ADR 0003），读不到目标应用里的文字，也不知道光标位置。

## 决策

1. **独立的修改快捷键，而不是在听写中识别指令。** 按住 Shift+F9（或 Super+Ctrl+Shift+X 切换）录一条修改指令。正文里常有「我们需要把接口改成异步的」这样的句子；如果在普通听写里识别指令，会把正文误当成修改。
2. **快捷键走 Omarchy 为听写后端预留的扩展点。** Omarchy 在默认后端为 `yuda` 时加载 `~/.config/yuda/shortcuts.lua`（`default/hypr/dictation-backend.lua`）；安装器写入并管理这个文件（首行标记，用户删掉标记后不再覆盖），卸载器移除它。不修改 Omarchy 自带的绑定。
3. **作用对象是语打上一次上屏的文字。** daemon 记住文字、时间与当时聚焦窗口的地址；只修改 10 分钟内、焦点未变的文字。
4. **执行方式：按字符数退格，再粘贴新版本。** 退格与粘贴都走 Hyprland `send_key_state`；发送前等用户松开修饰键（ADR 0007 的粘贴路径同样如此），否则 fcitx5 虚拟键盘的修饰键状态会失去同步。
5. **指令解析本地优先。** 替换、删除词语、撤回整段、首尾追加（含「问号」等标点名）由 `edit` 模块按规则处理，「九点」可匹配识别出的「9点」；规则无法理解的自由指令（「改得正式一点」「翻译成英文」）在开启 AI 纠错时交给 LLM。

## 被否决的方案

- **在普通听写里检测「把…改成…」**：误触发正文。
- **AT-SPI 读取目标文本**：Wayland 下各工具包支持不一，终端不可用。
- **Ctrl+Z 撤销粘贴**：终端里 Ctrl+Z 是挂起进程，不同应用的撤销粒度也不同。
- **Shift+← 选中再粘贴**：与退格的按键数相同，但在终端里不能选中。

## 影响

- 已知限制：上屏后用户又手动输入或移动了光标，退格会删到用户自己的文字。README 明确提示「听写之后、打字之前使用」。按 Unicode 字符数退格，组合 emoji 等多码位字形可能多删。
- 端到端场景 G、H、J、K 覆盖替换、撤回、命令行追加与 AI 自由指令。

## 本轮新增依赖及理由

AGENTS.md 要求说明新增 crate。本轮重写引入：

| crate | 用途 | 理由 |
|---|---|---|
| `toml_edit` | `yuda config set` / `migrate` 保留用户注释的就地修改 | toml 官方维护，`toml` 本身不保留格式 |
| `ureq` | LLM 纠错与改写的 HTTPS 请求 | 同步、轻量、维护活跃，无需异步运行时 |
| `tungstenite` + `rustls` + `webpki-roots` | 火山引擎流式识别的 WebSocket 与 TLS | 同步 WebSocket 事实标准；rustls 不依赖系统 OpenSSL |
| `flate2` | 火山引擎协议要求的 gzip 帧 | 事实标准 |
| `uuid` | 火山引擎 `X-Api-Connect-Id` | 协议要求的请求 ID |
| `chrono` | 识别历史的本地时间显示 | 原有依赖，恢复使用 |
